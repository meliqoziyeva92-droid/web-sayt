# Tayyor ovoz fayllari (ixtiyoriy)

Bu papkaga `kalit.mp3` nomli fayllarni qo'ysangiz, sayt ularni barcha qurilmalarda ishlatadi.
Masalan: `color_qizil.mp3`, `n3.mp3`, `welcome.mp3`.

Barcha kalitlar va matnlar `js/data.js` faylida. Odatda bu papka shart emas —
tarbiyachi ovozni saytning o'zida («Tarbiyachi paneli → Ovoz yozish») yozib qo'yishi mumkin.
