# Bog'cha O'yinlari

3–7 yoshli bolalar uchun ovozli, rasmli o'yinlar va tarbiyachilar uchun mashg'ulot rejalari.
Bolalar o'qishni bilmasa ham o'ynay oladi: savollar ovoz bilan aytiladi, javoblar — rasm, rang va shakllar.

## O'yinlar (12 ta)
Sanash · Ranglar · Shakllar · Hayvonlar · Mevalar · Transport · Kim nima yeydi? ·
Katta va kichik · Ortiqchasi · Juftini top · Odob va qoidalar · Alifbo

## Tarbiyachi paneli (🔒 tugmasi)
- **Mashg'ulot rejalari** — yosh guruhlari bo'yicha 10 ta tayyor reja, chop etish mumkin
- **Ovoz yozish** — har bir savolni o'z ovozingiz bilan yozib qo'yish, eksport/import
- **Sozlamalar** — kompyuter ovozi va tezligi

## Ishga tushirish
`index.html` ni brauzerda oching. Mikrofon va oflayn rejim uchun saytni https orqali
joylashtiring (masalan GitHub Pages: Settings → Pages → Branch).

## Fayllar
- `js/data.js` — o'yin ma'lumotlari va barcha ovozli iboralar
- `js/lessons.js` — mashg'ulot rejalari
- `js/games.js` — o'yinlar mantig'i
- `js/voice.js` — ovoz: yozilgan ovoz → `audio/*.mp3` → kompyuter ovozi
- `js/app.js` — sahifa va tarbiyachi paneli
- `css/style.css` — dizayn (Google Stitch dizayni asosida)
